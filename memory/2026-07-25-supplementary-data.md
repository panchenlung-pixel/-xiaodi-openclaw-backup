# 課程筆記 - 補充資料：Google 投資 Anthropic 的商業邏輯
日期：2026-07-25

## 教授補充的商業本質（賣鏟子邏輯）：
1. **龐大基礎設施需求：** Anthropic 每訓練一次 Claude，都需要大量的 GPU/TPU Storage、Networking、Database、Kubernetes、Security。
2. **Google 產品線全包：** Google 剛好全部都有產品可以收費。
3. **實際合作落地：** Anthropic 已宣布大幅擴充 Google Cloud 使用（包括 TPU、BigQuery、Cloud Run、AlloyDB 等），未來數年新增數 GW 等級的 TPU 運算容量。
4. **Google 實際獲利項目：**
   - Compute (算力)
   - Storage (儲存)
   - Networking (網路)
   - Managed Services (平台服務)
